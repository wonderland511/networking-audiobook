# Нетворкинг для разведчиков — аудиокнига

Веб-плеер для прослушивания аудиокниги «Нетворкинг для разведчиков».
10 частей, MP3 128 kbps, плеер с автопереходом к следующей части,
регулировкой скорости и сохранением позиции прослушивания.

## Как открыть

- Онлайн: страница GitHub Pages этого репозитория (`index.html`).
- Локально: открыть `index.html` в браузере (папка `audio/` должна лежать рядом).

## Файлы

`audio/00.mp3` … `audio/09.mp3`
